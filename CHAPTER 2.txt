CHAPTER 2 :- VARIABLES AND DATA TYPES

1)WHAT IS VARIABLES ?

-> A VARIABLE IS THE NAME GIVEN TO A MEMORY LOCATION IN A PROGRAM. 

FOR EXAMPLE:-
a=30
b="ABDULLAH"
c=71.22

2)WHAT IS DATA TYPES ?

-> PRIMARILY THESE ARE THE FOLLOWING DATA TYPES IN PYTHON:
1.INTEGERS
2.FLOATING POINT NUMBERS
3. STRINGS
4.BOOLEANS
5.NONE

PYTHON IS A FANTASTIC LANGUAGE THAT AUTOMATICALLY IDENTIFIES THE TYPE OF DATA FOR US.

FOR EXAMPLE:-
a=340
b="ABDULLAH"
c=712.22

RULES FOR DEFINING  A VARIABLE NAME (ALSO APPLIES TO OTHER IDENTIFIERS)
 A VARIABLE NAME CAN CONTAIN ALPHABETS,DIGITS,AND UNDERSCORES.
A VARIABLE NAME CAN ONLY START WITH AN ALPHABET AND UNDERSCORES.
A VARIABLE NAME CAN'T START WITH A DIGIT.
NO WHILE SPACE IS ALLOWED TO BE USED  INSIDE A VARIABLE NAME.

EXAMPLES  OF A FEW VARIABLES name are: "ABDULLAH",ONE8,SEVEN,SEVEN_,_SEVEN,SEVEN_8,ETC .

3) WHAT IS OPERATORS IN PYTHON  ?

->
ARITHEMATIC OPERATORS:+,-,*,/,%,//,ETC.
ASSINGMENT OPERATORS: =,+=,-=,*=,/=,ETC.
COMPARISION  OPERATORS: ==,>,>=,<=,<,!=,ETC. ->(RETURN VALUES OF COMPARISION OPERATORS IS BOOLEAN DATA TYPE FORM)

LOGICAL OPERATORS: and,or,not.

4) WHAT IS TYPE() FUNCTION AND TYPE CASTING ?

->
 type()FUNCTION IS USED TO FIND THE DATA TYPE OF A  GIVEN VARIABLE IN PYTHON.

a=31
type(a) #class<int>

b="31"
type(b) #class<str>

A NUMBER CAN BE  CONVERTED INTO STRING AND VICE VERSA(If possible).

THERE ARE MANY FUNCTIONS TO CONVERT ONE DATA TYPE INTO ANOTHER.

str(31) => "31" #integer to string conversion.
int("32") => #string to integer conversion.
float(32)  =>32.0 #integer to float conversion.

AND SO,ON
HERE"31"IS A STRING LITERALS AND 31 A NUMERIC LITERALS.

5) WHAT IS INPUT FUNCTION ?

-> 
INPUT FUNCTION IS FOR BASICALLY TAKING INPUT FROM USER .
EXAMPLE :-
a=(int(input("ENTER NUMBER 1")))

b=(int(input("ENTER NUMBER 2")))

print("NUMBER A IS",a)
print("NUMBER B IS",b)
print("SUM IS ",a+b)
