2) WHAT IS MODULES ?

-> A MODULE IS A FILE CONTAINING CODE WRITTEN  BY SOMEONE ELSE ( USALLY) WHICH CAN BE IMPORTED AND USED IN OUR PROGRAM.
A PYTHON MODULE IS LIKE A TOOLBOX FILLED WITH SPECIAL TOOLS(CODES)  .

3) WHAT IS PIP ?
->  PIP IS A THE PACKAGE MANAGER FOR PYHTON YOU CAN USE PIP TO INSTALL A MODULES ON YOUR SYSTEM.
(pip install flask) #INSTALLS FLASK MODULES.

4) TYPES OF MODULES ?
->  THERE ARE TWO TYPES OF MODULES IN PYTHON.
1.	BUILT IN MODULES(PREINSTALLED IN PYTHON)
2.	EXTERNAL MODULES(NEED TO INSTALL USING PIP)
SOME EXAMPLES OF BUILT IN FUNCTIONS ARE os,random,etc.
SOME EXAMPLES OF EXTERNAL MODULES ARE tensorflow , flask ETC.

5)USING PYTHON AS A CALCULATOR ?
-> WE CAN USE PYTHON AS A CALCULATOR BY TYPING (" pyhton" )ON THE TERMINAL.
THIS OPENS REPL ( READ EVALUATE  PRINT LOOP).
  
6) WHAT IS  COMMENTS ?
-> COMMENTS ARE USED TO WRITE SOMETHING WHICH PROGRAMMER DOES NOT WANT TO.
 
7) TYPES OF COMMENTS ?
-> THERE ARE TWO TYPES OF COMMENTS IN PYTHON.

1.SINGLE LINE COMMENTS : TO WRITE A SINGLE LINE COMMENTS JUST ADD A '#' AT START OF THE LINE.
#THIS IS A SINGLE-LINE COMMENT. 

2. MULTILINE COMMENTS: TO WRITE MULTI-LINE COMMENTS YOU CAN USE '#' AT EACH LINE
